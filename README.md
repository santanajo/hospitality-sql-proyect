# Hospitality SQL Project

## Overview
Real-world data analysis project using SQL and Python, based on actual sales data from two hospitality venues:
- **Cowboy** — breakfast venue
- **Lemuels** — hotel bar

## Dataset
- 787 real sales records from daily operations
- Data collected from physical paper tickets and entered manually
- Covers drinks, beverages, coffee, tea, and alcoholic drinks

## Technologies Used
- Python 3
- SQLite3
- SQL queries
- VS Code
- Pandas
- Git / GitHub

## Project Structure
- `create_sales_table.py` — Creates the database schema
- `import_csv.py` — Imports CSV data into SQLite
- `query_sales.py` — SQL analysis queries
- `update_location.py` — Data cleaning script

## Key Insights
- Top selling drink: Americano (257 units)
- Lemuels generated €630 in revenue
- Busiest period: 09:00 at Coburt (193 sales)
- 787 transactions analysed across both venues
